# Marketing Anaytics - Multi-Channel Ads Performance

## Project Overview
This project analyzes multi-channel advertising data (Google-Ads, Meta, TikTok) to identify profitable campaigns, optimize ad spend, and calculate core marketing KPIs.

## Tech Stack
- Python (Data Cleaning & Feature Engineering)
- Google BigQuery (Data Warehouse)
- SQL (STAR Schema & KPI Queries)
- POWER BI (Dashboarding)

## Data Source
Public dataset from Kaggle:
Global Ads Performance - Google, Meta, TikTok

## Key KPIs
- CTR (Click Through Rate)
- CPC (Cost Per Click)
- CAC (Customer Acquisition Cost)
- ROAS (Return On Ad Spend)

## Project Structure
- data/raw -> original dataset
- data/processed -> cleaned data
- python -> data cleaning scripts
- sql -> analytical queries
- powerbi -> dashboards
